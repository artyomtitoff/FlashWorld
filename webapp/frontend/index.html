Справка

Требования к фото: чёткое, без сильного размытия, желательно с перспективой (улица, комната, природа). Фото автоматически кропается под выбранное разрешение.

Траектория: 2–12 камер. Чем шире движение, тем больше новых областей дорисует модель. Для орбиты используй шаблон Orbit.

Текст: пиши на английском для лучшего качества (модель обучена на англ. промптах). Пример: “cozy mountain cabin, sunset, ultra detailed”.

Как это работает
FlashWorld — feed-forward модель генерации 3D-сцен из одного изображения/текста. Архитектура: Wan2.2-TI2V-5B трансформер генерирует латенты видео + фичи, декодер восстанавливает Pixel-Aligned 3D Gaussians (по 2 точки на пиксель), рендер через gsplat.

Пайплайн сайта: ты задаёшь камеры (позиция + кватернион + fx/fy/cx/cy), разрешение [N,H,W], промпты. Бэкенд кодирует текст через T5, делает 4 шага denoising с feedback, рендерит SPZ, который смотрится в браузере через Spark.

Демо-режим: если на сервере нет GPU/чекпоинта (проверь /api/health), генерация симулируется — создаётся процедурный SPZ для предпросмотра. Для реальной генерации запусти бэкенд с FLASHWORLD_DEMO=0 python site/backend/server.py и весом model.ckpt с HuggingFace.

CLI: python cli.py --input_dir ./examples --output_dir ./out --spz --ply --video даёт лучшее качество (без компрессии).
